# Stock textures

Seamless CC0 wood color maps used by the 3D simulation (`src/three/woodTexture.ts`).
All resized to 1K JPG; pine/oak/cherry rotated 90° so grain runs along +X.

| File | Source | Asset |
|---|---|---|
| pine.jpg | ambientCG | [Wood092](https://ambientcg.com/view?id=Wood092) |
| cedar.jpg | ambientCG | [Wood030](https://ambientcg.com/view?id=Wood030) |
| oak.jpg | Poly Haven | [oak_veneer_01](https://polyhaven.com/a/oak_veneer_01) |
| maple.jpg | ambientCG | [Wood095](https://ambientcg.com/view?id=Wood095) |
| walnut.jpg | Poly Haven | [dark_wood](https://polyhaven.com/a/dark_wood) |
| cherry.jpg | Poly Haven | [rosewood_veneer1](https://polyhaven.com/a/rosewood_veneer1) |
| plywood.jpg | Poly Haven | [plywood](https://polyhaven.com/a/plywood) |

Both sources license all assets as CC0 (public domain — no attribution required).
MDF, HDPE, aluminum, brass, and "other" have no photo texture; they get a
procedural tile generated at runtime.
